# Práctica 02 - Preprocesamiento de Datos

Práctica de la asignatura de **Inteligencia Artificial**, desarrollada en **Google Colab**.

## Contenido

En esta práctica se trabajó con:

- identificación de instancias, atributos, features y label;
- clasificación de variables;
- normalización Min-Max;
- estandarización Z-Score;
- análisis de valores extremos;
- limpieza de datos;
- dataset Palmer Penguins;
- división de datos en entrenamiento y prueba;
- `MinMaxScaler`, `StandardScaler` y `RobustScaler`.

## Herramientas

- Python
- Google Colab
- NumPy
- Pandas
- Matplotlib
- scikit-learn
