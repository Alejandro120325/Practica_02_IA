## Descripción

En esta práctica se estudia el **preprocesamiento de datos** previo al entrenamiento de modelos de Machine Learning. Se trabaja con un dataset inicial de estudiantes y posteriormente con el dataset real **Palmer Penguins**, aplicando limpieza, análisis y diferentes técnicas de escalado.

---

## Contenido

| Fase | Temas principales |
|---|---|
| **Fase 1** | Instancias, atributos, features, labels y clasificación de variables |
| **Fase 2** | Normalización Min-Max, Z-Score y análisis de valores extremos |
| **Fase 3** | Palmer Penguins, valores nulos y escalado de variables |
| **Fase 4** | División train/test, `MinMaxScaler`, `StandardScaler` y `RobustScaler` |

---

## Herramientas utilizadas

`Python` · `Google Colab` · `NumPy` · `Pandas` · `Matplotlib` · `scikit-learn`

---

## Conceptos trabajados

Identificación de variables y features, normalización Min-Max, estandarización Z-Score, tratamiento de valores extremos, limpieza de valores nulos, división train/test, prevención de *data leakage* y escalado con scikit-learn.
